# Contributing

This repository hosts the **documentation, releases and issue tracker** for AI Spend Monitor.
The source code is maintained privately (see [LICENSE](LICENSE)).

- **Bugs:** open an issue using the *Bug report* form. Running **AI Spend Monitor: Export Debug Report**
  in the editor and attaching it helps a lot; tokens, emails and amounts are removed automatically.
- **Ideas:** open an issue using the *Feature request* form.
- **Security:** please report privately, see [SECURITY.md](SECURITY.md).

The extension is free to use from Open VSX and the VS Code Marketplace.
